在家庭或办公网络中，当需要联网的终端设备数量众多（如 iPhone、Mac、Windows 电脑、Apple TV、游戏主机、智能家居）时，为每一台设备单独安装并维护代理客户端不仅繁琐，而且许多智能设备（如电视机、游戏机）根本无法安装第三方客户端。

在 **OpenWrt 软路由/硬路由** 上配置网络客户端（**OpenClash** 或 **PassWall**），打造全家共享的**透明代理 (Transparent Proxy)** 网络，是极客与高品质网络用户的终极解决方案。

本指南将深入讲解 OpenWrt 路由器端两大主流客户端的配置、一键订阅导入与 DNS 分流优化。

## 2. OpenClash 一键订阅与实操配置

**OpenClash** 是基于 Clash 内核的 OpenWrt 界面插件，完美延续了 Clash 的规则分流体系与强大的 Web 控制面板。

### 第一步：一键导入服务商订阅
1. 使用浏览器登录 OpenWrt 路由器后台（默认通常为 `192.168.1.1` 或 `192.168.2.1`）。
2. 在左侧菜单找到 **服务 -> OpenClash**。
3. 点击 **配置订阅** 选项卡。
4. 点击 **新增** 按钮：
   - 配置文件名：填写你的服务商名称。
   - 订阅地址：粘贴从服务商后台复制的 **Clash 订阅链接**。
   - 转换模板：选择“默认”或“Clash.Meta”。
5. 点击 **保存配置**，随后点击 **更新配置**，等待系统下载并转化配置文件。

### 第二步：核心运行模式选择
在 **运行模式** 设置中：
- **模式选择**：推荐选择 **`Fake-IP (增强模式)`**。此模式下路由器 DNS 响应速度极快，彻底规避 DNS 污染。
- **内核切换**：建议在全局设置中开启 **Clash.Meta (Mihomo)** 内核，以获得对 Hysteria 2 / TUIC 等下一代协议的支持。

### 第三步：启动服务与 Web 控制面板管理
1. 返回 **运行状态** 页面，点击 **启动 OpenClash**。
2. 启动成功后，点击页面上的 **控制面板 (Yacd / Clash-Dashboard)**。
3. 在控制面板的 **节点选择 (Proxies)** 选项中，测试节点延迟并指定所需的分流节点。

## 3. PassWall 轻量级配置教程

对于内存较小（如 256MB / 512MB）的硬路由，**PassWall** 是最节省资源的透明代理方案。

1. 进入 **服务 -> PassWall**，点击 **节点订阅**。
2. 添加订阅 URL 并保存，点击 **手动导入并更新节点列表**。
3. 进入 **开关与主节点设置**：
   - **TCP 节点**：选择一个低延迟的高速专线节点。
   - **UDP 节点**：可选择“与 TCP 相同”，确保外服游戏 UDP 顺利转发。
   - **域名解析模式**：选择 `ChinaDNS-NG` 或 `Dnsmasq 转发`。
4. 勾选 **主开关** 并保存应用。

## 4. 关键优化：DNS 污染防护与 SmartDNS 结合

透明代理中最常见的问题是 **DNS 域名污染**（访问海外网站被返回错误的 IP）。

```
防止 DNS 污染架构：
[客户端 DNS 请求] 
   │
   ├─► 国内域名 (Baidu/Taobao)  ──► 路由器直连解析 ──► 极速直连
   │
   └─► 海外域名 (Google/GitHub) ──► 走 Fake-IP / 代理隧道解析 ──► 无污染连通
```

1. **启用 Fake-IP**：确保 OpenClash 或 PassWall 托管了路由器的 53 端口 DNS 请求。
2. **结合 SmartDNS（可选）**：SmartDNS 负责测速筛选国内最快 DNS，而代理插件负责海外 DNS 转发，实现极致的网络加载速度。

## 5. 常见故障自救 FAQ

### Q1: 开启路由器代理后，局域网部分设备打不开网页，提示“无 Internet 连接”？
**答**：
1. 检查设备的 IP 设置，确保设备的 **网关 (Gateway)** 和 **DNS** 都指向 OpenWrt 路由器的 IP。
2. 如果局域网存在主旁路由架构，请检查旁路由的防火墙规则，确保添加了 NAT 伪装规则：
   `iptables -t nat -A POSTROUTING -j MASQUERADE`

### Q2: 国内应用（如微信、哔哩哔哩）经常加载缓慢或断流？
**答**：说明 GeoIP/GeoSite 规则库未及时更新。请在 OpenClash 规则管理中点击“更新 GEO 数据库”，确保国内流量精准直连。
