在 Android 操作系统（涵盖小米 MIUI/HyperOS、华为 HarmonyOS、vivo OriginOS、OPPO ColorOS 等品牌手机及平板）上，拥有丰富的网络连接工具可供选择。

针对安卓平台，目前最受推崇的两款客户端分别是 **Flclash**（基于 Clash.Meta 的新一代 UI 标杆）与 **Surfboard（冲浪板）**。本教程将详尽介绍这两款工具的下载安装、订阅导入及安卓特有的后台保活配置。

## 2. Flclash 快速上手实操

**Flclash** 是一款支持多平台的极简连接工具，其在 Android 端凭借优异的交互体验和完善的规则支持广受好评。

### 步骤一：获取正版 APK
1. 访问 Flclash 官方 GitHub Releases 页面，下载最新的 Android APK 文件（通常文件名带有 `android-arm64-v8a.apk`）。
2. 在手机文件管理器中点击安装包完成安装。

### 步骤二：订阅导入
1. 打开浏览器登录你的服务商后台。
2. 找到“订阅导入”，点击 **一键导入 Flclash / Clash**，系统将自动唤醒 App。
3. 若自动唤醒失败，点击服务商后台的 **复制订阅 URL**。
4. 打开 Flclash，点击底部导航栏的 **配置 (Profiles)**，点击右上角的 **`+`** 按钮，选择 **URL 导入**。
5. 粘贴复制的链接，点击 **保存 (Save)** 并等待节点刷新。

### 步骤三：启动连接与分流
1. 返回主界面，在节点列表中点击选中节点。
2. 确认路由模式为 **规则 (Rule)**。
3. 点击右下角的 **连接按钮**，首次开启时系统会弹出 `连接请求 (VPN)` 提示，点击 **确定/允许** 即可。

## 3. Surfboard（冲浪板）实操教程

**Surfboard** 拥有极其平滑的过渡动画与低功耗控制，非常适合注重续航的手机用户。

1. **下载方式**：可通过 Google Play 商店直连下载，或通过 GitHub 获取独立 APK。
2. **导入配置**：
   - 打开 Surfboard，点击底部的 **配置 (Config)** 标签页。
   - 点击右下角的 **`+`** 加号，选择 **从 URL 导入 (Import from URL)**。
   - 粘贴服务商提供的 Surfboard/Surge 订阅链接，点击 **导入**。
3. **连接生效**：在 **控制台 (Dashboard)** 页面点击右下角开关，开启代理服务。

## 4. 关键避坑：Android 后台保活与应用分流设置

安卓系统针对后台常驻应用有严苛的省电拦截机制，若未做特殊设置，经常会导致“锁屏后节点断连”。

```
后台保活三重防杀防护链：
[应用信息] -> 电池优化设为“无限制” -> 后台应用锁“上锁” -> 允许自启动与关联启动
```

### 电池优化白名单配置（必做）：
1. 长按客户端图标，点击 **应用信息 (App Info)**。
2. 找到 **省电策略 / 电池优化 (Battery Saver)**，将其修改为 **无限制 (No restrictions)** 或 **允许后台运行**。
3. 进入手机多任务后台卡片界面，向下划动客户端卡片或点击右上角锁头图标，将其 **锁定在后台**。

### 应用分流 (App Bypass / Split Tunneling)：
如果你希望特定安卓应用（例如国内银行 App、本地打车软件）完全绕过代理，可以在客户端设置中打开 **应用分流 (Bypass Apps)**，勾选不需要走代理的应用，避免出现无法定位或安全警告的问题。

## 5. 常见问题 FAQ

### Q1: 提示“无法创建 VPN 接口”怎么解决？
**答**：请检查手机是否开启了其他的 VPN 软件（如杀毒软件的隐私保护或另一款代理工具）。Android 系统同一时间只允许一个应用占用 VPN 接口。

### Q2: 导入节点后，显示“无网络连接”或“DNS 解析失败”？
**答**：请在手机设置中检查是否开启了系统自带的“私有 DNS (Private DNS)”。如果开启了第三方 DNS 选项（如 NextDNS/AdGuard），建议将其暂时切换为“关闭”或“自动”。
