## 1. 核心定位与技术架构解析

库洛米机场官方定位明确聚焦于：**全线端到端 IEPL 物理专线 / 多入口 BGP 汇聚 / 晚高峰低抖动抗拥塞**，其底层数据链路拓扑如下：

```
客户端 (Windows / macOS / iOS / Android / 软路由)
   │
   ▼
国内核心 BGP 多入口汇聚机房 (华东/华南电信、联通、移动多线就近接入)
   │
   ▼ 【物理内网点对点直连：彻底脱离公网，数据不走国际公共骨干网】
IEPL (International Ethernet Private Line) 国际专线光纤通道
   │
   ▼
境外亚太与欧美高规格数据中心落地出口 (大带宽吞吐保障)
   │
   ├─► 香港专线节点池 ──► 亚太极速互联 / 网页瞬开 / YouTube 4K 播放
   ├─► 台湾专线节点池 ──► 繁体中文流媒体 / 动画疯版权解锁
   ├─► 日本专线节点池 ──► 亚太高规格数据中心 / 稳定低抖动学术检索
   ├─► 新加坡专线节点池 ─► 东南亚国际网络枢纽 / Disney+ 流媒体
   └─► 美西专线节点池 ──► OpenAI ChatGPT-4o / Claude / Gemini AI 核心通道
```

### 1.1 端到端物理内网专线（IEPL）核心机制
* **物理脱离公网**：流量从国内 BGP 入口接收并打包后，直接经由运营商租用的物理二层内网专线传输至境外落地机房，全程不走公网国际出口骨干网；
* **抗干扰与零公网丢包**：公网国际出口在晚高峰常出现高负荷拥堵与丢包，而内网专线拥有独立专属的光纤物理通道，网络抖动控制极其出色；
* 有关物理内网专线与 BGP 中转机房的路由原理差异，详见 [IEPL/IPLC 专线与 BGP 中转深度剖析](/articles/bgp-transit-vs-direct-line-deep-dive)。

### 1.2 华东与华南 BGP 多入口冗余中转
* 国内部署了覆盖华东与华南主流网络枢纽的 BGP 入口，电信、联通与移动用户根据地理位置自动就近建立 TCP 连接，降低第一跳建联时延；
* 入口配置毫秒级健康探针，单一入口遭遇局部运营商路由调整时能平滑切换。

### 1.3 落地出口属性：大带宽 IDC 原生广播
* 落地机房选用亚太与欧美高规格商业数据中心，IP 广播类型为机房原生静态 IP，后端针对主流流媒体平台部署了智能分流解析。

### 3.2 严苛 AI 平台原生交互支持
