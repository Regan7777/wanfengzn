## 3. 全平台一键订阅导入与通用配置指引

无论你使用的是哪一个客户端，订阅导入的本质都是将服务商后台生成的专属配置 URL 绑定到客户端中。

### 方法 A：Web 一键跳转唤醒客户端（最快捷）
1. 用浏览器登录你的网络服务商后台，进入“仪表盘”或“订阅中心”。
2. 寻找与你客户端对应的 **一键导入** 按钮（如 `一键导入 Clash` / `导入到 Shadowrocket`）。
3. 浏览器弹窗提示“是否打开客户端应用”，点击 **允许/打开**。
4. 客户端将自动唤醒并弹出“保存订阅”提示框，确认即可同步节点列表。

### 方法 B：手动复制 URL 链接导入（通用防错）
如果一键跳转失败，请使用手动导入流程：

1. 在服务商后台点击 **复制订阅链接** (Copy Subscription URL)。
2. 打开客户端设置，定位到 **订阅管理 (Profiles / Subscriptions)** 菜单。
3. 点击 **添加 (Add)** 或 **`+`** 按钮。
4. 在 URL 输入框中粘贴刚刚复制的链接，命名为你的服务商名称，点击 **保存/刷新 (Download/Save)**。

```bash
# 导入成功的校验校验检查：
1. 节点列表中出现批量国家/地区节点（如 香港 IEPL 01, 日本 BGP 02）；
2. 显示订阅剩余流量与到期时间（支持 SSR/Clash 扩展协议）。
```

## 4. 核心模式解析：分流规则与连接设置

导入节点后，**切勿盲目直接连接**，请先确认以下核心参数设置：

```
路由分流模式选择指南：
┌──────────────────┬──────────────────────────────────────────┐
│ 规则模式 (Rule)  │ 🌟 推荐方案：国内流量直连，海外访问走代理 │
├──────────────────┼──────────────────────────────────────────┤
│ 全局模式 (Global)│ 所有流量强行走节点，可能导致百度/微信卡顿 │
├──────────────────┼──────────────────────────────────────────┤
│ 直连模式 (Direct)│ 所有流量都不走节点（即关闭代理）         │
└──────────────────┴──────────────────────────────────────────┘
```

1. **路由模式设置**：将路由模式调整为 **规则模式 (Rule/Config)**。
2. **节点选择**：在列表中选择一个延迟较低的中转或专线节点（如 `香港 01` 或 `新加坡 01`）。
3. **开启主开关**：点击客户端主界面的连接开关（首次连接需允许系统创建 VPN/网络代理配置）。

## 5. 常见疑难排查与配置 FAQ

### Q1: 为什么导入订阅提示“下载配置文件失败”或“ Invalid URL”？
**答**：通常有以下可能：
1. **服务商网址更新**：请重新登录后台复制最新的订阅链接；
2. **复制不完整**：检查链接结尾是否有空格或缺失字符；
3. **网络阻断**：在尝试导入时，先开启原有的有效节点或连接移动热点重试。

### Q2: 节点延时测试显示 `-1` 或 `Timeout` 怎么办？
**答**：
1. **对齐系统时间**：确认设备系统时间（Windows/Mac/手机）已开启自动同步；
2. **右键更新订阅**：可能服务商更新了节点域名，在订阅列表找到刷新按钮进行重新同步；
3. **检查防火墙设置**：Windows 用户检查是否被杀毒软件屏蔽了客户端的本地端口监听。
