在使用连接服务时，我们经常在节点名称中看到 `IEPL`、`IPLC`、`BGP`、`Transit` 或 `Direct` 等字眼。

这些字母代表了流量在传输过程中的**物理线路类型与网络架构**。搞懂这些线路的区别，能让你在挑选“机场推荐”方案时做到心中有数。

---

## 1. 常见线路架构透视

为了让大家直观理解，我们来看一条数据包从你的电脑到目标网站的传输路线：

### 1.1 IEPL / IPLC 专线（最高稳定性）
* **传输路径**：用户电脑 → 国内BGP入口 → **[物理内网专线 (不过公网)]** → 海外出口节点 → 目标网站。
* **优势**：不过公网GFW防火墙，受敏感时期影响极小，延迟稳定如一，丢包率趋近于0。
* **劣势**：带宽成本非常高昂，套餐价格相对稍高。

### 1.2 BGP 中转线路（高性价比）
* **传输路径**：用户电脑 → 国内多线BGP入口 → 公网加密隧道 → 海外出口节点 → 目标网站。
* **优势**：入口线路优质，跨运营商体验优秀，价格适中。
* **劣势**：隧道传输部分通过公网，敏感时期可能受到少量干扰。

### 1.3 公网直连线路（低预算）
* **传输路径**：用户电脑 → 运营商公网出口 → 国际海缆 → 目标服务器。
* **优势**：成本极低，适合低预算轻度浏览。
* **劣势**：高峰期网络拥堵严重，丢包率高，极易断连。

## 3. 如何选择适合自己的线路？

* **如果你需要稳定办公或频繁使用 AI 工具**：强力推荐选择 **IEPL / IPLC 专线** 方案。
* **如果你主要看视频、追剧、日常冲浪**：选择 **BGP 中转** 方案性价比最高。
* **如果你预算有限或作为备用线路**：可以考虑性价比更高的中转或直连方案。
