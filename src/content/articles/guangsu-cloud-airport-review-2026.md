## 1. 核心网络架构与底层技术解析

评估一家中转机场的综合稳定性，核心指标在于**入口骨干网络品质**与**协议抗封锁能力**。光速云的网络拓扑整体设计如下：

```
客户端 (Windows / macOS / Android / iOS)
   │
   ▼ 【标准 TLS 1.3 伪装 / 抵抗运营商 DPI 深度报文检测】
Trojan / V2Ray 加密传输通道
   │
   ▼
国内多线 BGP 智能中转入口集群 (电信 / 联通 / 移动动态分流)
   │
   ▼ 【私有隧道中转网络，绕过公网晚高峰跨国拥堵节点】
BGP 隧道转发与专线级骨干优化
   │
   ├─► 香港节点池 (1.0x) ──► 亚太极速互联 / 极低延迟网页秒开
   ├─► 台湾节点池 (1.0x) ──► 巴哈姆特动画疯 / 繁体中文流媒体
   ├─► 日本节点池 (1.0x) ──► 东京机房高质量回程 / YouTube 4K 秒开
   ├─► 新加坡节点池 (1.0x) ─► 东南亚枢纽 / Disney+ 影视版权库
   ├─► 美西节点池 (1.0x) ──► OpenAI ChatGPT-4o / Claude 原生交互
   └─► 欧洲多国节点池 (1.0x) ─► 英/德/法等主流出海跨境备用
```

### 1.1 多线 BGP 隧道智能汇聚入口
* **三网骨干均衡调度**：光速云在国内主要骨干网节点部署了多线 BGP 接入网关，不论用户处于电信、联通还是移动宽带环境，客户端均能通过 DNS Anycast 或接入层调度就近连入国内机房，大幅减少本地宽带到入口服务器的首跳延迟。
* **私有隧道中继转发**：国内入口与境外落地节点之间建立私有隧道中转，相比公网直连（直连在晚上 20:00-23:00 丢包率常飙升至 25% 以上），BGP 隧道能够有效过滤骨干公网抖动。关于中转与专线的底层路由差异，可参考博主撰写的 [BGP 多线中转与内网专线深度剖析](/articles/bgp-transit-vs-direct-line-deep-dive)。

### 1.2 Trojan 与 V2Ray 双协议栈互补
* **纯正 Trojan 协议**：采用成熟的 TLS 1.3 证书伪装机制，流量物理特征与普通浏览 HTTPS 网页保持一致，在敏感封锁时期具备优秀的抗封锁生存率。
* **V2Ray (VMess/VLESS) 广泛兼容**：满足老旧路由器固件、电视盒子及特殊定制客户端的订阅兼容需求，避免部分冷门设备无法解析单一协议订阅的尴尬。

### 1.3 落地出口属性与 IP 纯净度
* 境外节点选用高质量数据中心骨干机房，并对核心节点的出口路由配置了智能 SNI 分流，保障流媒体与 AI 服务不会因频繁切换脏 IP 而触发人机验证。

## 5. 多平台客户端适配与订阅配置指南

光速云支持标准的一键订阅转换与通用订阅导入，兼容各大主流平台。详细客户端选型与配置逻辑见 [全平台客户端选型与配置全指南](/articles/all-platforms-client-selection-and-config-guide)。

### 5.1 Windows / macOS 平台配置
1. 推荐下载现代客户端 **Clash Verge Rev**（基于 Mihomo/Meta 内核）或 **Sing-box**。
2. 登录光速云官网后台，在仪表盘点击【复制订阅链接】。
3. 打开 Clash Verge Rev，进入 `订阅 (Profiles)` 页面，粘贴链接并点击 `导入 (Import)`。
4. 在代理列表中选择 `规则模式 (Rule)`，核心节点选择香港或日本，即可畅通访问。

### 5.2 Android 平台配置
1. 推荐使用 **Clash Meta for Android** 或 **v2rayNG**。
2. 复制订阅链接后在客户端中选择“从剪贴板导入”，更新节点列表后开启系统 VPN 服务。
3. 开启路由分流设置为“绕过局域网及大陆地址”，避免国内 App 误走海外流量。

### 5.3 iOS 平台配置
1. 准备外区 Apple ID，前往 App Store 获取 **Shadowrocket**（小火箭）或 **Sing-box**。
2. 打开 Shadowrocket，点击右上角 `+` 号，类型选择 `Subscribe`。
3. 在 URL 栏粘贴官网订阅链接，备注填写 `光速云`，保存后右上角自动拉取节点。
4. 全局路由模式切换为 `配置 (Config)`，点击上方连接开关即可完成。
