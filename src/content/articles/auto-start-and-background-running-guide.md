对于每日都需要使用网络代理服务的用户来说，每次开机后手动寻找软件图标、双击打开、点击连接、最小化窗口的过程显得既繁琐又打断工作节奏。

通过将网络客户端配置为 **“开机自动启动 + 自动挂载系统代理 + 托盘静默运行”**，可以彻底消除使用感知，实现开机即享流畅网络的“无感上网”体验。

本教程由「晚风机场服务指南」编辑团队撰写，涵盖 Windows, macOS, Android 及 iOS 全平台设置步骤。

---

## 1. Windows 系统：开机自启与无弹窗静默运行

在 Windows 10/11 系统中，配合 Clash Verge Rev 或 Sing-box，按以下三步设置：

```
Windows 静默自启三步曲：
[开启 Auto Launch] ──► [勾选 Silent Start (最小化托盘)] ──► [安装 Service Mode (无 UAC 弹窗)]
```

### 详细步骤：
1. 打开客户端 **设置 (Settings)** 页面。
2. 勾选 **开机自启 (Auto Launch)**。
3. 勾选 **静默启动 (Silent Start / Start Minimized)**，确保开机时不弹出主界面窗口，仅在任务栏右下角托盘保留小图标。
4. 勾选 **自动开启系统代理 (Auto Enable System Proxy)**。
5. **解决 UAC 管理员弹窗**：若使用了 TUN 模式，进入 `系统服务 (Service Mode)` 点击 **Install (安装)**，安装完成后以后开机将自动静默提升权限，不再弹出 Win 系统防范弹窗。

## 2. macOS 苹果电脑：登录项与守护进程配置

在 macOS 系统（Intel 及 Apple Silicon M 系列芯片）下配置：

1. **客户端内部设置**：在 Clash Verge 或 Stash 设置中开启 `Auto Launch on System Startup`。
2. **系统登录项校验**：
   - 打开 Mac `系统设置 -> 通用 -> 登录项`；
   - 在“开机时打开”列表中，确认客户端已被成功添加；
   - 在“允许在后台运行”列表中，将客户端右侧开关保持 **开启** 状态。
3. **静默隐藏**：在登录项列表中勾选 `隐藏 (Hide)` 选项，开机后客户端卡片将自动缩回顶部菜单栏 (Menu Bar)。

## 3. Android 安卓端：自启动权限与防杀后台设置

安卓由于系统机制限制，除了应用内部设置，必须在手机系统层面授予权限：

```
安卓后台防护四重奏：
应用开机自启 ──► 电池无限制 ──► 多任务后台锁 ──► 自动连接系统 VPN
```

1. **开启应用内部自启**：在 Flclash / Surfboard 设置中开启 `系统启动时连接`。
2. **系统自启动权限**：打开手机 `设置 -> 应用管理 -> 权限管理 -> 自启动管理`，找到客户端并开启 **允许自启动** 和 **允许关联启动**。
3. **应用后台锁定**：进入手机卡片式任务后台，向下滑动客户端卡片点击 **加锁**，防止清理内存时被一键误杀。

## 4. iOS / iPadOS：快捷指令自动接管（可选）

iOS 系统受限于安全隔离，应用无法在后台隐蔽自启。但可以通过内置的 **“快捷指令 (Shortcuts)”** 实现自动化：

1. 打开 iOS 自带的 **快捷指令** App，切换到 **自动化** 标签页。
2. 点击右上角 **`+`**，创建个人自动化。
3. 选择触发条件（如：`当连接到我家 Wi-Fi 时` 或 `当打开指定 App 时`）。
4. 执行动作选择 `Shadowrocket / Stash -> 开启连接`。
5. 勾选 **立即运行**，实现满足特定场景时自动后台接管网络。

## 5. 常见问题 FAQ

### Q1: 开机自启后，访问网页提示“代理服务器拒绝连接”？
**答**：通常是因为客户端未完成彻底加载前，系统代理就已被强制挂载。请在客户端设置中将“开机延迟启动 (Launch Delay)”设为 `5 秒`，等待网络网卡驱动初始化完毕后再建立连接。

### Q2: 电脑重启后，之前开启的 TUN 模式失效了？
**答**：请检查是否没有安装“系统服务 (Service Mode)”。以普通权限运行的 TUN 模式在重启后无法自动重新绑定虚拟网卡，必须安装服务模式将其注册为系统服务。
